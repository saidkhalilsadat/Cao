# Civil Affairs Organization of Afghanistan (CAO) – Website

Official static website for CAO (plain HTML, CSS and JavaScript – no build step, no dependencies).

This is the **flat version**: every file sits in one folder, so it can be uploaded to GitHub directly.

## Files

- `index.html` – home page
- `about.html`, `strengths.html`, `what-we-do.html`, `projects.html`, `gallery.html`, `contact.html`
- `community-development.html`, `health-nutrition.html`, `agriculture-livestock.html`, `education.html`, `disaster-management.html` – one page per program
- `style.css` – all styles (colors and fonts are variables at the top)
- `main.js` – animations, menu, lightbox
- `logo.png`, `logo-white.png`, `favicon*.png`, `apple-touch-icon.png` – logo with transparent background
- `*-640.jpg`, `*-1200.jpg`, `*-1600.jpg` – photos in three sizes
- `404.html`, `robots.txt`, `.nojekyll`

## Publish on GitHub Pages

1. Create a repository and upload all files (including `.nojekyll`).
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. The site goes live at `https://<username>.github.io/<repository>/`.
